# HTTP Authentication from Target Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `rest.*` and `http.request` send the `Authorization` header their target's settings call for (basic or OAuth2 client credentials). SOAP connectors send basic auth. The real-environment runner refuses placeholder or incomplete credentials.

**Architecture:**
- **`RestAuthenticator`** is a new class in `idm-connector-rest`. It turns a target's `RestApiConfig` into a header value, uses Spring Security's `AuthorizedClientServiceOAuth2AuthorizedClientManager` for OAuth, and returns an `OperationResult<String>` (no data means unauthenticated).
- **Steps:** the three HTTP steps call it through a small engine helper, `RestAuthorization.apply`, unless the step already sets `Authorization`.
- **SOAP:** the connectors set `BindingProvider.USERNAME_PROPERTY`/`PASSWORD_PROPERTY` through a shared helper.
- **Guard 5** in `RealEnvironmentScenarios` checks credentials for the targets and SOAP steps the selected scenarios use.

**Tech Stack:** Java 21, Spring Boot 3.5.6, Spring Security OAuth2 Client 6.5, JAX-WS (Metro), JUnit 5, AssertJ, WireMock.

**Spec:** `docs/specs/2026-09-25-http-auth-design.md` (commit 473282f). **Ticket:** ITF-23.

## Global Constraints

- **The engine stays Spring-free.** No file under `idm-test-engine/src/main/java` may contain `import org.springframework` (`NoSpringDependencyTest`). `RestAuthenticator.authorization(...)` exposes no Spring types.
- **Which header a target gets:**
  - `use-oauth: true` → `Authorization: Bearer <token>`, from a client-credentials token for `oauth-client-name`
  - otherwise, `username` and `password` both non-blank → `Authorization: Basic base64(username:password)`, in UTF-8
  - neither set → no header
- **Only one of username/password set** is a configuration error, and so is `use-oauth` with no, or an unknown, registration. Either fails the step before anything is sent.
- **The step's own header wins.** If the step's headers contain `Authorization` in any letter case, the authenticator is **not called** and nothing is added.
- **Secrets never appear** in step messages, failure messages, captures, `scenario-results.json`, or log output from these components. Passwords, client secrets, tokens and `Authorization` values are all secrets. Messages name the target, the registration, the property and the variable, never a value.
- **Guard 5's variables** are formed by upper-casing the property, removing `-` and replacing `.` with `_`. For example:
  - `IDM_TEST_REST_IDM_PASSWORD`
  - `IDM_TEST_SOAP_USERNAME`
  - `SPRING_SECURITY_OAUTH2_CLIENT_REGISTRATION_SAP_CLIENTSECRET`
- **The placeholders guard 5 refuses:**
  - REST `idm`: `idmadmin` / `idmpass`
  - SOAP: `idmadmin` / `idmpass`
  - OAuth `sap`: `sap-test-client` / `sap-test-secret`
  - OAuth `workday`: `workday-client` / `workday-secret`
  - OAuth `servicenow`: `snow-client` / `snow-secret`
- **Commit messages** end with a blank line, `ITF-23`, then `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Build commands:**
  - Always pair `-pl` with `-am`.
  - Single-test runs add `-Dsurefire.failIfNoSpecifiedTests=false`.
  - If the IDE reports "Unresolved compilation problems", the `.class` files are stale; run `./mvnw clean test`.
- **"Green"** means every test runs with 0 failures, 0 errors and 0 skips.

```java
package com.idm.test.connector.rest.client;

import com.idm.test.connector.rest.config.RestProperties;
import com.idm.test.core.model.ErrorType;
import com.idm.test.core.model.OperationResult;
import org.springframework.security.oauth2.client.AuthorizedClientServiceOAuth2AuthorizedClientManager;
import org.springframework.security.oauth2.client.InMemoryOAuth2AuthorizedClientService;
import org.springframework.security.oauth2.client.OAuth2AuthorizeRequest;
import org.springframework.security.oauth2.client.OAuth2AuthorizedClient;
import org.springframework.security.oauth2.client.OAuth2AuthorizedClientProviderBuilder;
import org.springframework.security.oauth2.client.OAuth2AuthorizedClientService;
import org.springframework.security.oauth2.client.registration.ClientRegistrationRepository;
import org.springframework.security.oauth2.core.OAuth2AuthorizationException;
import org.springframework.security.oauth2.core.OAuth2Error;

import java.nio.charset.StandardCharsets;
import java.util.Base64;

/**
 * Turns a REST target's settings into the {@code Authorization} header its requests carry.
 * <p>
 * {@code use-oauth} wins: a client-credentials token for {@code oauth-client-name}, fetched,
 * cached and renewed by Spring Security's own authorized-client manager (no custom token code).
 * Otherwise a username and password give HTTP basic authentication, and a target with neither
 * is unauthenticated. Anything half-configured is a failure, so a request is never sent with
 * credentials the author did not fully give.
 * <p>
 * Never throws, and never puts a password, secret, token or header value in a message or log:
 * messages name the target and the registration only.
 */
public class RestAuthenticator {

    private final ClientRegistrationRepository registrations;
    private final AuthorizedClientServiceOAuth2AuthorizedClientManager manager;

    /**
     * @param registrations the OAuth2 client registrations, or null when none are configured
     * @param clients       where authorized clients (tokens) are kept, or null for an in-memory store
     */
    public RestAuthenticator(ClientRegistrationRepository registrations, OAuth2AuthorizedClientService clients) {
        this.registrations = registrations;
        if (registrations == null) {
            this.manager = null;
            return;
        }
        OAuth2AuthorizedClientService service =
                clients != null ? clients : new InMemoryOAuth2AuthorizedClientService(registrations);
        this.manager = new AuthorizedClientServiceOAuth2AuthorizedClientManager(registrations, service);
        this.manager.setAuthorizedClientProvider(
                OAuth2AuthorizedClientProviderBuilder.builder().clientCredentials().build());
    }

    /** An authenticator for basic and unauthenticated targets only. */
    public static RestAuthenticator withoutOAuth() {
        return new RestAuthenticator(null, null);
    }

    /**
     * @param target the target's name, used in messages and as the OAuth principal
     * @param config the target's settings
     * @return the full header value; success with no data when the target is unauthenticated; or
     * a failure whose message names the target and what to fix
     */
    public OperationResult<String> authorization(String target, RestProperties.RestApiConfig config) {
        if (config.isUseOAuth()) {
            return bearer(target, config.getOauthClientName());
        }

        boolean hasUsername = present(config.getUsername());
        boolean hasPassword = present(config.getPassword());
        if (!hasUsername && !hasPassword) {
            return OperationResult.success(null, "REST target '" + target + "' is unauthenticated");
        }
        if (hasUsername != hasPassword) {
            return OperationResult.failure("REST target '" + target + "' has a "
                    + (hasUsername ? "username but no password" : "password but no username")
                    + "; set both idm.test.rest." + target + ".username and .password, or neither",
                    ErrorType.CONFIGURATION_ERROR);
        }

        String credentials = config.getUsername() + ":" + config.getPassword();
        return OperationResult.success(
                "Basic " + Base64.getEncoder().encodeToString(credentials.getBytes(StandardCharsets.UTF_8)),
                "REST target '" + target + "' uses basic authentication");
    }

    private OperationResult<String> bearer(String target, String registrationId) {
        if (!present(registrationId)) {
            return OperationResult.failure("REST target '" + target + "' sets use-oauth but no oauth-client-name",
                    ErrorType.CONFIGURATION_ERROR);
        }
        if (registrations == null) {
            return OperationResult.failure("REST target '" + target + "' uses OAuth2 registration '" + registrationId
                    + "', but no OAuth2 client registrations are configured (spring.security.oauth2.client.registration)",
                    ErrorType.CONFIGURATION_ERROR);
        }
        if (registrations.findByRegistrationId(registrationId) == null) {
            return OperationResult.failure("REST target '" + target + "' names OAuth2 client registration '"
                    + registrationId + "', which is not configured under spring.security.oauth2.client.registration",
                    ErrorType.CONFIGURATION_ERROR);
        }

        String failed = "OAuth2 token request for registration '" + registrationId + "' (target '" + target + "') failed: ";
        try {
            OAuth2AuthorizedClient client = manager.authorize(
                    OAuth2AuthorizeRequest.withClientRegistrationId(registrationId).principal(target).build());
            if (client == null) {
                return OperationResult.failure("OAuth2 registration '" + registrationId + "' (target '" + target
                        + "') gave no access token; its authorization-grant-type must be client_credentials",
                        ErrorType.CONFIGURATION_ERROR);
            }
            return OperationResult.success("Bearer " + client.getAccessToken().getTokenValue(),
                    "REST target '" + target + "' uses OAuth2 registration '" + registrationId + "'");
        } catch (OAuth2AuthorizationException e) {
            OAuth2Error error = e.getError();
            String description = error.getDescription() == null ? "" : " " + error.getDescription();
            return OperationResult.failure(failed + "[" + error.getErrorCode() + "]" + description,
                    ErrorType.AUTHENTICATION_ERROR);
        } catch (RuntimeException e) {
            return OperationResult.failure(failed + e.getClass().getSimpleName(), ErrorType.AUTHENTICATION_ERROR);
        }
    }

    private static boolean present(String value) {
        return value != null && !value.isBlank();
    }
}

package com.idm.test.engine.steps;

import com.idm.test.connector.rest.client.RestAuthenticator;
import com.idm.test.connector.rest.config.RestProperties;
import com.idm.test.core.model.OperationResult;

import java.util.Map;

/**
 * Adds a target's {@code Authorization} header to a request, shared by rest.request,
 * rest.verify and http.request so the three cannot drift apart.
 * <p>
 * The step's own header wins: if the author wrote {@code Authorization} in any letter case, the
 * target's settings are not consulted at all, so no token is fetched for a request that will not
 * use it and a scenario can send bad credentials on purpose. The added header is never a step
 * parameter, so it never reaches a message, a capture or the results file.
 */
final class RestAuthorization {

    private static final String AUTHORIZATION = "Authorization";

    private RestAuthorization() {
    }

    /**
     * Call only after {@link RestTargets#resolveBaseUrl} succeeded, so the target exists.
     *
     * @return null when {@code headers} is ready to send, or a failure message naming the step
     */
    static String apply(String stepName, String target, RestProperties properties,
                        RestAuthenticator authenticator, Map<String, String> headers) {
        if (headers.keySet().stream().anyMatch(AUTHORIZATION::equalsIgnoreCase)) {
            return null;
        }
        OperationResult<String> result = authenticator.authorization(target, properties.getRest().get(target));
        if (result.isFailure()) {
            return stepName + " could not authenticate: " + result.getMessage();
        }
        result.getData().ifPresent(value -> headers.put(AUTHORIZATION, value));
        return null;
    }
}

```java
package com.idm.test.connector.soap.client;

import com.idm.test.connector.soap.config.SoapProperties;
import jakarta.xml.ws.BindingProvider;

/**
 * Applies {@code idm.test.soap.username}/{@code password} to a JAX-WS port as HTTP basic
 * authentication, shared by the role and resource connectors. Both set: sent. Neither set: an
 * unauthenticated endpoint. Only one: refused, because a request with half the credentials is
 * never what was meant. Messages name properties, never values.
 */
final class SoapCredentials {

    private SoapCredentials() {
    }

    static void apply(BindingProvider port, SoapProperties properties) {
        boolean hasUsername = present(properties.getUsername());
        boolean hasPassword = present(properties.getPassword());
        if (hasUsername != hasPassword) {
            throw new IllegalStateException("idm.test.soap." + (hasUsername ? "username" : "password")
                    + " is set but idm.test.soap." + (hasUsername ? "password" : "username")
                    + " is not; set both for basic authentication, or neither");
        }
        if (hasUsername) {
            port.getRequestContext().put(BindingProvider.USERNAME_PROPERTY, properties.getUsername());
            port.getRequestContext().put(BindingProvider.PASSWORD_PROPERTY, properties.getPassword());
        }
    }

    private static boolean present(String value) {
        return value != null && !value.isBlank();
    }
}

```java
    /**
     * Guard 5. Refuses credentials the run is about to use when they are still application.yml's
     * placeholders or only half given: for each REST target the selected scenarios use, and for
     * SOAP when they use roles.* or resources.*. An unauthenticated target (nothing set) passes.
     * Messages name the property and the variable that sets it in every profile, never a value.
     * Runs after guard 4, so every target here is configured.
     */
    static void requireCredentials(Set<String> restTargets, boolean usesSoap, RestProperties rest,
                                   SoapProperties soap, Environment environment) {
        for (String target : new TreeSet<>(restTargets)) {
            RestProperties.RestApiConfig config = rest.getRest().get(target);
            if (config == null) {
                continue;
            }
            String prefix = "idm.test.rest." + target + ".";
            if (config.isUseOAuth()) {
                requireOAuthClient(target, config.getOauthClientName(), environment);
            } else {
                requirePair(prefix + "username", config.getUsername(), prefix + "password", config.getPassword(),
                        REST_CREDENTIAL_PLACEHOLDERS.get(target));
            }
        }
        if (usesSoap) {
            requirePair("idm.test.soap.username", soap.getUsername(), "idm.test.soap.password", soap.getPassword(),
                    SOAP_CREDENTIAL_PLACEHOLDER);
        }
    }

    /** Guard 5's entry point: loads {@code files} and checks the credentials they need. */
    static void requireCredentialsIn(String scenarioDir, List<String> files, RestProperties rest,
                                     SoapProperties soap, Environment environment) {
        List<Scenario> scenarios = loadForGuards(scenarioDir, files);
        requireCredentials(restTargets(scenarios), usesSoap(scenarios), rest, soap, environment);
    }

    /** Whether any scenario has a roles.* or resources.* step, in steps or cleanup. */
    static boolean usesSoap(List<Scenario> scenarios) {
        for (Scenario scenario : scenarios) {
            List<StepSpec> entries = new ArrayList<>(scenario.steps());
            entries.addAll(scenario.cleanup());
            for (StepSpec step : entries) {
                if (step.type().startsWith("roles.") || step.type().startsWith("resources.")) {
                    return true;
                }
            }
        }
        return false;
    }

    /**
     * The environment variable that sets {@code property} in every profile, by Spring's relaxed
     * binding: upper case, dashes removed, dots to underscores.
     */
    static String variableFor(String property) {
        return property.toUpperCase(Locale.ROOT).replace("-", "").replace('.', '_');
    }

    private static void requirePair(String userProperty, String user, String passwordProperty, String password,
                                    Credentials placeholder) {
        boolean hasUser = user != null && !user.isBlank();
        boolean hasPassword = password != null && !password.isBlank();
        if (hasUser != hasPassword) {
            String present = hasUser ? userProperty : passwordProperty;
            String missing = hasUser ? passwordProperty : userProperty;
            throw new IllegalStateException(present + " is set but " + missing + " is not. Set "
                    + variableFor(missing) + " as well, or give neither for an unauthenticated target.");
        }
        if (placeholder == null) {
            return;
        }
        if (hasUser && user.equals(placeholder.username())) {
            refusePlaceholder(userProperty);
        }
        if (hasPassword && password.equals(placeholder.password())) {
            refusePlaceholder(passwordProperty);
        }
    }

    private static void requireOAuthClient(String target, String name, Environment environment) {
        String nameProperty = "idm.test.rest." + target + ".oauth-client-name";
        if (name == null || name.isBlank()) {
            throw new IllegalStateException("idm.test.rest." + target + ".use-oauth is true but " + nameProperty
                    + " is not set. Set " + variableFor(nameProperty) + " to a " + REGISTRATION + "<name> entry.");
        }
        String idProperty = REGISTRATION + name + ".client-id";
        String secretProperty = REGISTRATION + name + ".client-secret";
        String clientId = environment.getProperty(idProperty);
        String secret = environment.getProperty(secretProperty);
        if (clientId == null || clientId.isBlank()) {
            throw new IllegalStateException("REST target '" + target + "' uses OAuth2 registration '" + name
                    + "', which is not configured: " + idProperty + " is not set. Set " + variableFor(idProperty) + ".");
        }
        if (secret == null || secret.isBlank()) {
            throw new IllegalStateException("REST target '" + target + "' uses OAuth2 registration '" + name
                    + "', but " + secretProperty + " is not set. Set " + variableFor(secretProperty) + ".");
        }
        Credentials placeholder = OAUTH_CLIENT_PLACEHOLDERS.get(name);
        if (placeholder != null && clientId.equals(placeholder.username())) {
            refusePlaceholder(idProperty);
        }
        if (placeholder != null && secret.equals(placeholder.password())) {
            refusePlaceholder(secretProperty);
        }
    }

    private static void refusePlaceholder(String property) {
        throw new IllegalStateException(property + " is still application.yml's placeholder, so no real credential"
                + " was given. Set " + variableFor(property) + ".");
    }

```markdown
### Authentication

`rest.request`, `rest.verify` and `http.request` authenticate with their target's settings. Nothing goes in the scenario:

| Target settings (`idm.test.rest.<target>.*`) | Header sent |
|---|---|
| `use-oauth: true`, `oauth-client-name: <registration>` | `Authorization: Bearer <token>`, a client-credentials token from `spring.security.oauth2.client.registration.<registration>`, cached and renewed by Spring Security |
| `username` and `password` | `Authorization: Basic ...` |
| neither | none |

- **Configuration errors:** a username without a password, the reverse, or `use-oauth` naming an unknown registration fails the step before anything is sent.
- **The step's own header wins:** a step that sets `Authorization` itself, in any letter case, sends exactly that header, and the target's credentials are not used. Use this for negative tests:

  ```yaml
  - http.request:
      target: idm
      method: GET
      path: /users
      headers:
        Authorization: "Basic bm9ib2R5Ondyb25n"
      as: denied
  ```

- **Keep secrets in target settings, not in YAML:** a header written in a scenario is a resolved parameter and is written to the results file unredacted, while the header added from target settings never is.

`roles.*` and `resources.*` send HTTP basic authentication when `idm.test.soap.username` and `password` are both set.
```
